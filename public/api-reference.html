⚖️ Spread Trader
signal(ctx) → string
Entry/exit decisions for co-integrated pair trading. Called each bar to determine position.
Context Object (ctx)
ctx.zscore
number
30-bar rolling z-score of the spread. Values > 2 mean overvalued, < -2 mean undervalued.
ctx.spread
number
Raw spread (log price difference) between pair A and B.
ctx.priceA, ctx.priceB
number
Current prices of both legs in the pair.
ctx.pos
number (1/-1/0)
Current position: 1=LONG, -1=SHORT, 0=FLAT.
ctx.bar
number
Current bar index (0 to 299).
ctx.beta, ctx.pairA, ctx.pairB
number / string
Hedge ratio (beta) and pair names.
Return Values
'LONG_SPREAD'
Enter long: buy spread A, short spread B.
'SHORT_SPREAD'
Enter short: sell spread A, buy spread B.
'FLAT'
Close any open position.
'HOLD'
Maintain current position.
Example
function signal(ctx) { if (ctx.zscore < -2 && ctx.pos === 0) return 'LONG_SPREAD'; if (ctx.zscore > 2 && ctx.pos === 0) return 'SHORT_SPREAD'; if (ctx.pos === 1 && ctx.zscore > 0.5) return 'FLAT'; return 'HOLD'; }
🚀 Momentum Trainer
signal(ctx) → string
Trend-following decisions based on SMA crossover and momentum confirmation.
Context Object (ctx)
ctx.price
number
Current price.
ctx.sma_fast (SMA10), ctx.sma_slow (SMA30)
number
10 and 30-period simple moving averages.
ctx.mom_20, ctx.mom_5
number
20-bar and 5-bar momentum percentages.
ctx.atr
number
20-bar average true range as % of price.
ctx.high, ctx.low
number
20-bar high and low prices.
ctx.pos, ctx.bar
number
Position (1=LONG, 0=FLAT) and bar index.
Return Values
'LONG'
Enter long position.
'FLAT'
Exit position.
'HOLD'
Maintain current position.
🎯 Price War
quote(ctx) → { bid, ask } | { half_spread_bps, skew_factor }
Quote two-sided prices in a market-making simulation. Called each bar.
Context Object (ctx)
ctx.mid
number
Current mid price.
ctx.vol
number
20-bar realized volatility (%).
ctx.inventory
number
Current net position (units). Max 100.
ctx.inventory_limit
number
Max allowed inventory (100).
ctx.bar
number
Current bar index (0-199).
ctx.last_buy_vol, ctx.last_sell_vol
number
Recent order flow (units).
Return Values
{ bid: 99.95, ask: 100.05 }
Explicit bid/ask prices.
{ half_spread_bps: 5, skew_factor: 0.8 }
Shorthand: spread in basis points, skew left (skew < 1) or right.
🌐 Regime Rider
allocate(ctx) → { SPX: %, NDX: %, BONDS: %, CASH: % }
Allocate portfolio based on regime detection. Allocation should sum to 100%.
Context Object (ctx)
ctx.regime
string
'BULL' | 'NEUTRAL' | 'BEAR' based on market signals.
ctx.equity_returns, ctx.bond_returns
number
Recent period returns (%).
ctx.vix
number
Volatility index approximation.
🤖 Bot Builder
In Bot Builder, you design trading bots by selecting strategy types (Momentum, Mean-Reversion, Market-Making, Adaptive) and configuring parameters (entry threshold, exit threshold, position size, stop loss). The system then evaluates your bot's performance across 3 synthetic markets in a tournament setting.
🔗 Arbitrage Sprint
Arbitrage Sprint is a timed trading challenge where you identify and exploit mispricings across linked instruments (spot-futures, index arbitrage, convertible arbs). The game presents price mismatches and you decide whether to trade and at what size.
🧺 Basket Blitz
Basket Blitz challenges you to decompose factor exposure in multi-asset portfolios and hedge residual risk. You analyze correlations and manage tail risk across equities, bonds, and alternatives.
📣 Options Outcry
Options Outcry is a derivatives market simulation where you price and trade vanilla options with live Greeks. Quote bid/ask prices, manage Greeks (delta, gamma, vega), and navigate implied volatility changes.
📂 CMI Challenge
CMI Challenge is a multi-asset book management game. You manage exposures across equities, commodities, and rates with risk limits. Track VaR, notional exposure, and Greeks. Optimize PnL within constraints.
🏃 Quant Relay
Quant Relay is a time-boxed research challenge. You work through factor families (value, momentum, quality, low-volatility) and compute alpha signals, information coefficients, and decay rates under time pressure.
🧪 Alpha Factory
Alpha Factory lets you mine alternative data signals (sentiment, web traffic, corporate actions) and backtest their predictive power. Measure IC decay and optimize holding periods to maximize information value.
